## Notes

### How The Internet Works
The Internet is a global network of networks.
It's a bunch of connected computers.

---

### Intro to the Web
- #### The Internet
    Global network of interconnected computers that communicate via TCP/IP. Network of networks.

- #### The Web
    The World Wide Web is an information system where documents and others resources are available over the Internet. Documents are transferred via **HTTP** (Hyper Text Transfer Protocol).

- #### Web Server
    A computer* that can satisfy requests on the Web.  
\* "server" is also used to refer to the software running on the computer.

- #### Client
    The computer that accesses a server.
---

### HTTP Request/Response Cycle & Understanding the roles of HTML, CSS and JS
When we want to access a webpage, our browser sends an HTTP request to a web server.

The web server processes the request and sends back an HTTP response.

-> The response can contain files such as:

- **HTML** — defines the structure of the webpage.
- **CSS** — defines the styling and appearance.
- **JavaScript** — adds behavior and interactivity.

These are the three core technologies that browsers understand and use to display and make webpages interactive.

> In simple terms:  
> Browser → HTTP Request → Web Server → HTTP Response → Browser
---

### Front-End and Back-End
Front-end development focuses on the technologies that run in the browser, while back-end development focuses on the technologies that run on servers.

- **Front end:** HTML, CSS, JavaScript, etc. → runs mainly in the browser.
- **Back end:** Server-side code, databases, APIs, etc. → runs on servers.

**Note:** JavaScript can be used for both front-end and back-end development.
